# Brag Plan: EKSA E910 Companion

## What is this app?
A modern, native Windows system-tray companion for the EKSA E910 5.8GHz Wireless Gaming Headset with true 10-band hardware DSP PEQ control, 7.1 Surround & Mic ENC toggling, calibrated battery tracking, and custom sound profiles (featuring the ZXG preset).

## The angle
Legacy OEM headset tools are bloated, clunky, and broken. EKSA E910 Companion brings zero-bloat C# WPF speed, true fixed-point biquad hardware DSP filter programming, and an Obsidian Electric Purple aesthetic.

## Hook (0 - 3.0s)
"Your EKSA E910 headset deserves better than broken OEM software."

## Key moments (3.0s - 13.0s)
- **Scene 1: The Obsidian Interface**: Window slides in with smooth 3D tilt, revealing genuine 5.8GHz hardware dongle detection (`COL01`).
- **Scene 2: True Hardware DSP EQ**: Highlighting the **ZXG Preset**, 10 sliders actively gliding into position (`+2, +3, +2, -2, 0, +1, 0, +2, -3, +3 dB`).
- **Scene 3: Hardware Control & Calibrated Battery**: One-click 7.1 Virtual Surround & Mic ENC toggles, paired with accurate active-usage battery calculation.
